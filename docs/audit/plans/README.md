## ⚠️ Sicherheits-Callout (kein Plan — sofort manuell erledigen)

Im lokalen **`.git/config`** (Remote-`origin`-URL) liegt ein **GitHub Personal Access
Token (`ghp_…`)** im Klartext eingebettet. Der Wert wird hier bewusst nicht
wiedergegeben. Maßnahme:

1. Token bei GitHub **widerrufen** (Settings → Developer settings → Personal access tokens).
2. Neuen Token erzeugen und stattdessen einen Credential-Helper oder SSH-Remote nutzen
   (`git remote set-url origin git@github.com:WolfgangKoe/Arbiter.git`).
3. Prüfen, ob der Token je in CI-Logs oder Commits aufgetaucht ist.

`.git/config` ist nicht eingecheckt, aber jede `git remote -v`-Ausgabe (z. B. in Logs)
leakt den Wert — daher Rotation, nicht nur Entfernung.
